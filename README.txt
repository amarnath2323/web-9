ONLINE TOY STORE - EXPERIMENT 9
Form Validation and Routing using AngularJS

Files:
1. register.html  - Customer registration form with AngularJS validation.
2. toy_store.html - Online Toy Store website with AngularJS ngRoute routing.

Features:
- Registration fields: name, password, age, mobile number, email, gender and state.
- required, ng-pattern, min, max, type=email and ng-disabled validation.
- Validation messages are displayed near the fields.
- Routed pages: Home, Toys, My Cart and Contact.
- Add toys to cart, remove toys and place a sample order.
- AngularJS 1.6.9 and ngRoute are loaded using CDN links.

How to run:
1. Extract this ZIP folder.
2. Open the extracted folder in Visual Studio Code.
3. Open register.html with Live Server to test form validation.
4. Open toy_store.html with Live Server to test routing and toy store pages.
5. Internet connection is required for the AngularJS CDN scripts.

Note:
This is a front-end lab demonstration. Cart/order data is stored in browser memory only;
it is not connected to a database or payment gateway.
